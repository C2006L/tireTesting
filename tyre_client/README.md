# 轮胎缺陷检测系统 V3.0 (简化版)

一个基于PyQt5的轮胎缺陷检测系统，支持批量检测和实时显示。

## 🚀 快速开始

### 运行系统
```bash
python start_app.py
```

### 基本使用
1. **启动系统** - 运行后自动进入就绪状态，无需手动开启服务
2. **开始检测** - 点击左侧工具栏的"开始检测"按钮
3. **选择文件夹** - 选择包含轮胎图像的文件夹
4. **自动处理** - 系统自动循环检测所有图像
5. **查看结果** - 左侧显示原始图像，右侧显示检测结果
6. **直接关闭** - 点击X按钮或菜单直接退出，无需确认

## ✨ 系统特性

- ✅ **无服务依赖** - 启动即可使用，无需手动开启服务
- ✅ **批量检测** - 支持文件夹批量处理
- ✅ **智能缩放** - 图像自动适应窗口大小，保证完整显示
- ✅ **直接关闭** - 一键退出，无确认对话框
- ✅ **实时显示** - 检测过程中实时显示图像和结果
- ✅ **算法集成** - 提供模板，易于集成自定义算法

## 🖼️ 图像显示

### 支持格式
- PNG, JPG, JPEG, BMP, TIFF等常见图像格式

### 显示特性
- **智能缩放** - 自动适应窗口大小
- **保持比例** - 维持原始图像纵横比
- **完整显示** - 确保图像不被截断
- **实时调整** - 窗口大小改变时自动适应

### 两种集成方式

#### 方式一：修改算法模板（推荐）
编辑 `src/algorithms/detection_template.py` 文件，实现四个核心方法：

```python

def preprocess_image(image):       # 图像预处理  
def detect_defects(image):         # 缺陷检测（核心）
def postprocess_result(image, result):  # 结果后处理
```

#### 方式二：直接集成
在 `src/pages/SimpleMainWindow.py` 中搜索 `算法集成区域` 注释，直接添加您的检测代码。
